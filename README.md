# bln_multicoords

Collect multiple coordinates in RedM for spawn points, zones, paths, and other script data.

![bln multicoords redm script - standalone - bln studio](./.github/assets/banner.png)

## Documentation

Full install, commands, configuration, and usage:

**[BLN Multi Coords — docs.bln-studio.com](https://docs.bln-studio.com/docs/free-redm-scripts/bln_multicoords.html)**

## Quick start

1. Add `ensure bln_multicoords` to your `server.cfg`
2. In-game: `/mcoords`
3. Add points, **BACKSPACE** to finish, then **Copy** on the card
